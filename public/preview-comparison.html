All Changes

What Was Fixed & Why

01

Logo Letter-Spacing

Fixed 12px → relative 0.32em. At 12px the letters read as scattered. Relative values scale with the font and stay proportional.

02

Heading Line-Height

0.95 → 1.08–1.12. Sub-1.0 line-height causes physical overlap on large serifs. The correct range for display headings is 1.0–1.15.

03

Button Arrow Gap

28px → 14px. A gap of 28px on a small button almost doubles the button width. The arrow should feel attached, not like an afterthought.

04

Button Hover States

No interaction → 0.22s transitions + box-shadow. Static buttons feel broken in 2025. Hover states communicate quality and responsiveness.

05

Contact Section

3-column grid → centered flex column. Each element was isolated in its own column with nothing relating to anything else. Now they share a visual axis.

06

Gold Hairline Rule

Nothing → 44×1px gold rule. Sections without visual entry points read as filler. A single line gives the section intention before you read a word.

07

Decorative Quote Mark

No mark → 8rem gold ". Luxury brands use typographic marks as design elements. Without it, a quote is just text. With it, it's a moment.

08

Mobile Navigation

Hidden → hamburger + overlay. The single biggest functional failure. Mobile users had no way to navigate the site. Now they have a full menu.

09

Intro Layout

Centered stack → two-column grid with gold vertical rule. The most generic layout possible became an editorial moment with visual tension.

10

Difference Numerals

Tiny uppercase labels → large faded 01 02 03 in Cormorant. Three identical items now have hierarchy. Your eye moves through the list naturally.

11

Pause Section

Didn't exist → one statement, full width, large type. The page needed a moment that stops the scroll. Now it has one before the contact CTA.
